    The shop on the corner gets paid.

    LocalLegacy. Two Flutter apps, one for the customer and one for the shopkeeper, talking to one Go backend: 20+ JWT-secured endpoints, Redis in front of the hot paths, and PostgreSQL storing every payment as an encrypted QR record.

    One API in the middle.

    Both apps speak to the same Go service. It checks the token, asks Redis first, and writes to PostgreSQL only when it has to.
